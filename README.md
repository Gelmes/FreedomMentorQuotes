# Freedom Mentor Quotes

Auto-generated quote slides used as image assets for the
[@freedom_mentor_sora](https://instagram.com/freedom_mentor_sora) Instagram
account (linked via the *Freedom Mentor Quotes* Facebook page).

Posts are rendered from the React slide deck at
`shadow-slides/src/slides` and published to Instagram via the Graph API. The
files under [`posts/`](./posts) are the raw image assets referenced by each
upload (the public `raw.githubusercontent.com` URL is what gets passed as the
`image_url` parameter to `/{ig-user-id}/media`).
